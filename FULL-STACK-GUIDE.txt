🔄 HOW MEAL/DEAL SYNC WORKS

When you add/update a meal in the Admin Panel:

1. Admin Panel → API Server
   ├─ POST /api/admin/menu (create)
   ├─ PATCH /api/admin/menu/:id (update)
   └─ Data saved to data/store.json

2. Mobile App ← API Server
   ├─ Fetches from /api/mobile/menu on app load
   ├─ Shows latest meals with real prices + offers
   └─ NO rebuild needed - fetches from API dynamically

3. Website ← API Server
   ├─ Fetches from /api/mobile/menu on page load
   ├─ Shows same meals as app
   └─ Real-time sync via MenuContext

KEY: The app and website fetch menu data from the API dynamically.
     They do NOT store meals locally. Every load pulls fresh data.
     New meals show immediately without app rebuild!

📱 INSTALLATION ON SAMSUNG S10+

When the build completes:

1. Get the APK:
   • Download from the build URL above
   • File: com.the_zoro.rfcrealfarmerschicken-production-<version>.apk

2. Enable USB Debugging on S10+:
   ├─ Go to Settings → About Phone
   ├─ Tap "Build number" 7 times
   ├─ Go back to Settings → Developer Options
   └─ Enable "USB Debugging"

3. Connect USB and Install:
   ├─ Run: adb install <path-to-apk>
   ├─ Or drag APK to Android Studio's device window
   └─ Or transfer to phone and tap to install

4. First Launch:
   ├─ Phone must be on same WiFi as backend (192.168.0.119)
   ├─ App will connect to: http://192.168.0.119:8080
   ├─ Login: Any phone number + OTP (server logs OTP for dev)
   └─ Browse meals from /api/mobile/menu
